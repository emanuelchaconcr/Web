# Emanuel Chacón – Infrastructure Engineer

[![Website](https://img.shields.io/website?url=https://emanuelchacon.cr)](https://emanuelchacon.cr)

**Portfolio** showcasing experience in virtualización, storage, backup, automatización y cloud híbrido.

## 🚀 Quick start
```bash
# Clone the repo
git clone https://github.com/emanuelchaconcr/Web.git
cd Web
# Serve locally (any static server, e.g.)
npx serve .   # or python -m http.server 8000
```

## 📂 Project structure
- `index.html` – Home page (now with SEO meta tags and Google Fonts).
- `proyectos/` – Project case studies (each enriched with OG tags).
- `herramientas/` – Handy calculators and diagnostics (meta tags added).
- `enlaces/` – Links to portfolio, LinkedIn, GitHub, etc.
- `css/`, `js/` – Styles and scripts.
- `assets/` – Favicon SVG.
