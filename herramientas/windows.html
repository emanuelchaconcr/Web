Windows Server Helper

Checklists guiados con PowerShell para salud del servidor, servicios, Active Directory, red, RDP, DNS y Windows Update.

PowerShellActive DirectoryRDPWindows Update

Cómo usarlo

Elige el componente y el problema. Completa los datos de tu entorno y se insertarán en los comandos. Marca cada paso al terminarlo: el progreso se guarda en este navegador.

Documentar el caso

Usa Notas del caso para registrar hallazgos y descarga el checklist en .md para adjuntarlo al ticket o al informe de incidente.
